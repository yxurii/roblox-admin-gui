# Horizon Panel

A simple and clean graphical user interface (GUI) execution script designed for modern Roblox exploit environments. 

## ⚡ Core Features

* **Click-to-Run Interface:** A fully interactive button panel—no text commands or chat prefixes required.
* **Auto-Completion Engine:** A dynamic overlay that accurately searches and matches player names as you type them into target fields.
* **Custom Keybinds:** Configurable keyboard shortcuts to show or hide the graphical window instantly.
* **Sleek Layout:** A modern, draggable UI framework designed for fast and easy navigation.

---

## 🚀 How to Use

1. Copy your `loadstring` script execution line.
2. Paste it into your exploit software utility.
3. Click **Execute** while inside the game workspace.
4. Press the designated keybind (Default: **Right Control**) to toggle the panel on your screen.
